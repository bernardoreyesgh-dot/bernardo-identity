# Fonts

Latin WOFF2 files from the Fontsource packages, taken from the npm registry:

- Anton 400 (display)
- EB Garamond 400, 600, 700 (text)
- IBM Plex Mono 400, 500 (captions)

These are temporary. Once Node.js is installed, switch to `npm install @fontsource/anton @fontsource/eb-garamond @fontsource/ibm-plex-mono` and import the CSS from the packages instead.

Spanish accents (á é í ó ú ñ and ¿ ¡) fall in the Latin subset, which is the one used here.
